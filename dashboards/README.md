# Global Superstore - Executive Sales Intelligence Dashboard (Power BI)

##  Project Overview
This project features an interactive **Sales Intelligence Dashboard** built using Power BI. It is designed to provide executive-level visibility into key business metrics, regional performance, and product profitability across global markets.

##  Key Features
- **Executive KPIs:** Comprehensive view of Total Sales, Profit, Order Count, Quantity Sold, and Profit Margin.
- **Trend Analysis:** Dual-axis visualization comparing sales volume against net profit trends over time.
- **Regional & Market Breakdown:** Performance distribution across major geographical segments (Asia Pacific, Europe, USCA, etc.).
- **Product Insights:** Dynamic ranking of top revenue-driving products.
- **Theme Variations:** Designed in both **Light Mode** and **Dark Mode** for enhanced accessibility and reporting preferences.

##  Tech Stack & Tools
- **Tool:** Power BI Desktop
- **Language:** DAX (Data Analysis Expressions)
- **Data Transformation:** Power Query
- **Data Modeling:** Star Schema / Relational Data Model
